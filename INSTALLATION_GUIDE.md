## 📥 STEP 2: Install on TradingView

### For Supply & Demand:

1. **Open the file** `institutional_supply_demand.pine`
2. **Select ALL the code** (Ctrl+A or Cmd+A)
3. **Copy it** (Ctrl+C or Cmd+C)
4. **Open TradingView** in your browser
5. **Click "Pine Editor"** at the bottom of the screen
6. **Click "Open"** → **"New indicator"**
7. **Delete any default code** in the editor
8. **Paste** your copied code (Ctrl+V or Cmd+V)
9. **Click "Save"** at the top
10. **Name it** "Institutional Supply & Demand"
11. **Click "Add to Chart"** button

✅ **Done! You should see zones appearing on your chart**

---

### For Order Blocks:

## 🔔 STEP 5: Set Up Alerts

**Don't stare at charts all day - let the indicator alert you!**

### How to Set Alerts:

1. **Click the ⏰ icon** (top right of TradingView)
2. **Click "Create Alert"**
3. **Condition:** Select your indicator name
4. **Select alert type:**
   - "New Demand Zone" (when new buy zone forms)
   - "New Supply Zone" (when new sell zone forms)
   - "Price in Demand Zone" (price touches buy zone)
   - "Price in Supply Zone" (price touches sell zone)
5. **Set notifications:**
   - ✅ App notification (TradingView mobile app)
   - ✅ Email notification
   - ✅ Webhook (advanced)
6. **Click "Create"**

**Recommended:** Set alerts for **"Price in Demand/Supply Zone"** only

## ⚠️ Troubleshooting

### Problem: No zones appearing

**Solution 1:** Check timeframe
- Switch to **4H or 1H**
- Lower timeframes (5min, 15min) are noisier

**Solution 2:** Lower strictness
- Settings → Impulse Multiplier → Try **1.3** or **1.8**

**Solution 3:** Wait for volatility
- Zones form during market movement
- Low volatility = fewer zones

**Solution 4:** Check history
- Right-click chart → "Load More Data"
- Need enough bars for analysis

---

### Problem: Too many zones

**Solution 1:** Increase strictness
- Settings → Impulse Multiplier → Try **2.0** or **2.5**

**Solution 2:** Reduce display
- Settings → Max Zones to Display → Try **5** or **8**

**Solution 3:** Use Order Blocks
- Switch to Order Block indicator (stricter)

---

### Problem: Zones keep disappearing

**This is NORMAL and CORRECT!**

- Touched zones = Mitigated = Dead
- System auto-deletes them
- This keeps your chart clean
- Only fresh zones matter
- Don't enable "Show Touched Zones"

---

### Problem: Can't see labels

**Solution 1:** Enable labels
- Settings → Show Zone Labels → ON

**Solution 2:** Zoom out
- Chart might be too zoomed in

**Solution 3:** Check colors
- Labels might blend with background
- Change chart theme

---

### Problem: Indicator not loading

**Solution 1:** Check Pine Script version
- Must be Pine Script v6
- Check first line: `//@version=6`

**Solution 2:** Clear cache
- TradingView → Refresh page
- Try different browser

**Solution 3:** Check syntax
- Make sure you copied ALL the code
- No missing brackets or quotes
