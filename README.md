## 🚀 Quick Start (5 Minutes)

### Step 1: Use The Combined Indicator

**File:** `institutional_zones_combined.pine` ⭐

**Everyone should start with this!**
- See both S&D and OB zones
- Toggle types on/off as needed
- Learn both methodologies
- Identify confluence setups

### Step 2: Install on TradingView

1. Open **TradingView** → Pine Editor (bottom)
2. Click "Open" → "New indicator"
3. Copy ALL code from `institutional_zones_combined.pine`
4. Paste into editor
5. Click "Save" → Name it "Institutional Zones Complete"
6. Click "Add to Chart"

### Step 3: Configure Settings

**Zone Types (Both ON Recommended):**
```
[✓] Show Supply & Demand Zones
[✓] Show Order Block Zones
```

**Supply & Demand:**
```
S&D Impulse Multiplier: 1.5
S&D Max Base Candles: 3
```

**Order Blocks:**
```
OB Impulse Multiplier: 2.0
OB BOS Lookback: 10
```

**General:**
```
Max Zone Age: 30 days
Max Zones Per Type: 15
Show Touched Zones: OFF
```

### Step 4: Set Your Timeframe

**Best Timeframes:**
- 🥇 **4H (4 Hour)** - Swing trading, highest quality
- 🥈 **1H (1 Hour)** - Day trading, good balance
- 🥉 **Daily** - Position trading, major zones

### Step 5: Start Trading

1. Wait for zones to appear (green = demand, red = supply)
2. Set alerts for "Price in Zone"
3. When price returns, wait for confirmation candle
4. Enter with proper risk management (1-2% per trade)
5. Zone touched = Auto-deleted (find next opportunity)
