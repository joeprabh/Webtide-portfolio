======================================
INSTALL: institutional_zones_final.pine
======================================

STEP 1: COPY CODE
- Open file: institutional_zones_final.pine
- Select ALL (Ctrl+A)
- Copy (Ctrl+C)

STEP 2: TRADINGVIEW
- Go to TradingView.com
- Open any chart
- Click "Pine Editor" (bottom)
- Click "Open" → "New indicator"
- Delete all default code
- Paste (Ctrl+V)
- Click "Save"
- Name it: "Institutional Zones"
- Click "Add to Chart"

STEP 3: USE 4H OR 1H TIMEFRAME
- Switch chart to 4H or 1H

STEP 4: WAIT
- Zones appear when ALL 4 rules pass:
  1. Red→Green (demand) or Green→Red (supply)
  2. Body > 2.0x ATR
  3. Fair Value Gap exists
  4. Break of Structure
  
- These are RARE when combined
- Scroll back to see historical zones

SETTINGS (if needed):
- Click ⚙️ next to indicator name
- Lower "Impulse Multiplier" to 1.5 or 1.3 to see more zones

WHAT YOU'LL SEE:
- Green rectangles = DEMAND zones (buy)
- Red rectangles = SUPPLY zones (sell)
- Small labels "DEMAND" or "SUPPLY"
- Labels show when zones are created
- Zones deleted when touched
